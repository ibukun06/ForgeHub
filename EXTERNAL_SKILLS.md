# ForgeHub — Curated External Skills & Resources

These are external resources worth evaluating. Do not install entire collections blindly.

## 1. Official Antigravity Skills Documentation
https://antigravity.google/docs/skills

Use this as the authoritative reference for:
- skill format
- workspace vs global scope
- SKILL.md frontmatter
- skill discovery

Antigravity's current workspace location is:
`.agents/skills/<skill-folder>/SKILL.md`

## 2. Awesome Antigravity Skills
https://github.com/LichAmnesia/awesome-antigravity-skills

A curated directory of Antigravity-compatible skills and collections.

Useful for discovering:
- development
- code quality
- design/frontend
- testing
- security
- workflow skills

Recommended approach:
Search the catalog and copy only the specific skill you need.

## 3. UI/UX Pro Max
https://github.com/krishnakanthb13/antigravity_global_skills/tree/main/ui_ux_pro_max

Useful for design exploration and UI/UX patterns.

Important:
Use it as design intelligence, not as ForgeHub's design authority. ForgeHub's own DESIGN_SYSTEM.md remains the product source of truth.

## 4. Frontend Design / Webapp Testing collection
https://github.com/guanyang/antigravity-skills

Contains skills such as:
- frontend-design
- ui-ux-pro-max
- web-design-guidelines
- webapp-testing

Useful as a source of individual skills rather than a reason to install the entire collection.

## 5. Superpowers
https://github.com/obra/superpowers

A general agentic software-development methodology covering planning, debugging, testing, TDD, Git workflows and related engineering practices.

This is the external collection I would evaluate first for ForgeHub's engineering workflow.

Do NOT blindly combine every Superpowers skill with every ForgeHub skill. Overlapping instructions can cause conflicts.

## 6. Agentic Awesome Skills
https://github.com/sickn33/agentic-awesome-skills

Large cross-agent skill collection with Antigravity-compatible skills.

Useful for selectively finding:
- design
- testing
- development
- architecture
- security
- automation

Do not install the entire collection into ForgeHub.

## 7. Antigravity Awesome Skills
https://github.com/Pvmsirish/Antigravity

Large Antigravity-focused collection with installers, catalogues and bundles.

Use its catalogue to discover skills, then select a small set relevant to ForgeHub.

## 8. Google Codelab — Authoring Antigravity Skills
https://codelabs.developers.google.com/getting-started-with-antigravity-skills

Useful for understanding how to create and install project-specific skills.

## Recommended external shortlist for ForgeHub

Start with:
1. UI/UX Pro Max — visual research/pattern exploration
2. Frontend Design — frontend quality
3. Web Design Guidelines — design/accessibility review
4. Webapp Testing — browser QA patterns
5. Superpowers — engineering workflow/TDD/debugging

Then keep ForgeHub-native skills as the final authority for product-specific decisions.

## Important
Skills are instructions, not magic capabilities.

A skill can improve reasoning and process, but it cannot replace:
- browser verification,
- repository inspection,
- testing,
- product context,
- good requirements,
- human review.

Audit third-party skills before trusting them with destructive commands, credentials, deployments, migrations or external services.
