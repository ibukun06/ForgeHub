# ForgeHub Performance

Optimize measured problems, not imagined ones.

Inspect:
- unnecessary client components
- excessive API calls
- duplicate fetching
- oversized assets
- image handling
- expensive rendering
- bundle growth
- database query inefficiency
- loading waterfalls
- layout shifts

For each recommendation:
- identify evidence,
- explain impact,
- propose the smallest justified change,
- verify after implementation.

Do not add dependencies solely for perceived performance.
